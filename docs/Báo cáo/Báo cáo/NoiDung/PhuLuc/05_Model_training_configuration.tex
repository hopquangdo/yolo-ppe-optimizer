\chapter{MODEL TRAINING CONFIGURATION}

\begin{lstlisting}[caption={Mẫu cấu hình huấn luyện và tối ưu cần lưu cùng run}]
experiment:
  name: <experiment-name>
  seed: <seed>
dataset:
  name: <dataset-name>
  version: <dataset-version>
  train_split: <path-or-id>
  val_split: <path-or-id>
  test_split: <path-or-id>
model:
  architecture: <yolo-variant>
  pretrained: <checkpoint>
  image_size: <width-height>
training:
  epochs: <epochs>
  batch_size: <batch-size>
  optimizer: <optimizer>
  learning_rate: <learning-rate>
pruning:
  method: <structured-method>
  ratios: [0.20, 0.30, 0.40]
qat:
  enabled: true
  scheme: <quantization-scheme>
export:
  onnx_opset: <opset>
  tensorrt_precisions: [fp16, int8]
\end{lstlisting}

Bản cấu hình thực tế cần bổ sung hash mã nguồn, phiên bản framework, môi trường
CUDA, đường dẫn artifact và kết quả metric để bảo đảm khả năng tái lập.

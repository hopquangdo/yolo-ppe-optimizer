\section{Kết chương}

Chương 5 đã mô tả cách hiện thực Cloud Control Plane, Edge Agent, Edge Runtime,
Monitoring, Dashboard và AI Copilot. Các thành phần sử dụng state machine,
schema, checksum, idempotency và audit để giữ tính nhất quán qua kết nối phân
tán. Chương 6 xây dựng phép đo để kiểm chứng cả hiệu quả tối ưu model lẫn chất
lượng vận hành của nền tảng.

\section{Xây dựng Edge Runtime}

\subsection{Camera Input}

Camera Input hỗ trợ \cbs{USB/CSI/RTSP/video file thực tế}. Module cấu hình độ
phân giải, FPS, timeout và chính sách reconnect. Timestamp được gắn khi frame đi
vào pipeline để đo end-to-end latency. Hàng đợi capture có giới hạn và ưu tiên
frame mới trong tác vụ thời gian thực.

\subsection{YOLO Inference}

Runtime đọc manifest để tạo preprocessing đúng với model: letterbox, đổi thứ tự
kênh, scale và layout tensor. Input/output buffer được cấp phát một lần và tái sử
dụng. Warm-up chạy trước khi runtime chuyển sang trạng thái ready.

\subsection{TensorRT}

TensorRT module deserialize engine, tạo execution context và CUDA stream. Module
kiểm tra input binding, shape và data type so với manifest. Lỗi deserialize hoặc
thiếu plugin trả reason code rõ ràng để Edge Agent kích hoạt rollback.

\subsection{Result Processing}

Result Processing giải mã output, áp dụng confidence threshold, NMS và ánh xạ
label. Kết quả chuẩn hóa gồm frame id, timestamp, model version và danh sách
detection. Output được gửi tới \cbs{API/message broker/lưu trữ hoặc giao diện
thực tế}.

\subsection{Runtime Metrics}

Runtime xuất thời gian capture, preprocess, inference, postprocess, end-to-end,
FPS, queue depth và frame drop. Histogram được ưu tiên cho latency thay vì chỉ
trung bình. Metrics gắn model version để so sánh trước và sau deployment.

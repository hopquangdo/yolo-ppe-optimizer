\section{Xây dựng Cloud}

\subsection{Fleet Management}

Fleet Management hiện thực API tạo và tra cứu node, endpoint nhận heartbeat và
worker đánh dấu offline. Khi đăng ký, node nhận định danh và credential theo
\cbs{cơ chế thực tế}. Heartbeat cập nhật last-seen, capability, runtime summary
và model version nhưng không làm mất lịch sử trạng thái.

Các thao tác thay đổi label hoặc vô hiệu hóa node phát domain event để
Deployment cập nhật khả năng chọn target. Danh sách node hỗ trợ lọc theo device
class, online status, label và model version.

\subsection{Model Registry}

Model Registry cung cấp luồng tạo model version, upload artifact, xác nhận
checksum, ghi benchmark và release. Binary được lưu trong \cbs{object storage},
metadata lưu trong \cbs{database}. Service từ chối release khi thiếu manifest,
checksum hoặc compatibility.

Manifest tối thiểu chứa model name/version, precision, input shape, label map,
preprocess, postprocess, runtime requirement và danh sách artifact theo device
class. API download không trả đường dẫn lưu trữ nội bộ mà sinh URL có hạn hoặc
stream qua service.

\subsection{Deployment Management}

Deployment Management nhận model version, selector, strategy và guardrail. Khi
khởi tạo, service chụp target snapshot để rollout không thay đổi ngoài ý muốn nếu
label node bị sửa giữa chừng. Scheduler tạo command theo batch và chờ kết quả
trước khi tiến tới batch tiếp theo.

State machine của deployment và từng target được lưu bền vững. Worker khởi động
lại có thể tiếp tục từ trạng thái trước đó. Rollback tạo command trỏ về last known
good version, không sửa ngược lịch sử deployment.

\subsection{Command Management}

Command Management lưu command trong database và publish theo mẫu outbox để
tránh trạng thái đã ghi nhưng chưa gửi. Consumer nhận acknowledgement/result và
cập nhật trạng thái theo thứ tự hợp lệ. Mỗi command có correlation id liên kết
deployment, người yêu cầu hoặc Copilot plan.

Các loại lệnh chính gồm deploy model, update configuration, start runtime, stop
runtime, restart runtime và collect diagnostic. Payload được kiểm tra bằng schema
riêng cho từng loại lệnh.

\subsection{Incident Management}

Incident Management tiếp nhận detection event từ Monitoring, chống trùng theo
fingerprint và tạo timeline. API hỗ trợ acknowledge, assign, add note, change
severity, resolve và reopen. Mọi thay đổi lưu actor và thời điểm để phục vụ audit.

Incident view tổng hợp affected node, runtime, model version, deployment gần
nhất, metric và command. Dữ liệu tổng hợp được lấy qua query service thay vì sao
chép toàn bộ sang Incident aggregate.

\subsection{Knowledge Management}

Knowledge Management hỗ trợ upload tài liệu, tạo revision, chia chunk, embedding
và keyword indexing. Pipeline ingestion lưu trạng thái để retry từng bước. Chunk
được gắn metadata như loại tài liệu, model/device liên quan, ngôn ngữ và quyền.

Hybrid search thực hiện keyword search và vector search, sau đó hợp nhất kết quả
theo \cbs{thuật toán/reranker thực tế}. Kết quả trả snippet, score, document id và
revision để Copilot tạo citation nội bộ.

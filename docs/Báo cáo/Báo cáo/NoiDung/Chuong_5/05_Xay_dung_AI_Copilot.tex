\section{Xây dựng AI Copilot}

\subsection{Agent Architecture}

Copilot gồm conversation API, context builder, planner, tool registry, policy
check, executor và response composer. System prompt mô tả vai trò, giới hạn và
quy tắc citation; dữ liệu trạng thái được lấy từ tool thay vì nhúng cố định trong
prompt.

\subsection{Knowledge Search}

Khi câu hỏi cần tài liệu, Agent gọi \texttt{Knowledge.search} với truy vấn và bộ
lọc, chọn ứng viên rồi gọi \texttt{Knowledge.get}. Câu trả lời lưu danh sách
document revision đã dùng. Nếu không có bằng chứng đủ mạnh, Copilot phải nêu rõ
thiếu dữ liệu thay vì suy đoán.

\subsection{MCP Tools}

Các domain tool được công bố qua \cbs{MCP server/cơ chế tool registry thực tế}.
Mỗi tool có tên, mô tả, JSON schema đầu vào, schema đầu ra và phạm vi quyền. Tool
server ánh xạ yêu cầu sang application service, không cho mô hình truy cập thẳng
database.

\subsection{Tool Calling}

Executor validate tham số do mô hình sinh, gắn user identity và gọi policy engine.
Read-only tool có thể chạy ngay khi được phép. Write tool chỉ tạo plan; sau khi
người dùng phê duyệt, executor gọi application service bằng idempotency key và
lưu toàn bộ audit.

\subsection{Conversation Memory}

Conversation Memory lưu message và summary có giới hạn. Thông tin nhạy cảm được
lọc trước khi đưa lại vào model. Memory không được dùng như nguồn sự thật cho
trạng thái node; mọi tham chiếu như ``thiết bị đó'' được giải quyết thành node id,
sau đó tool lấy dữ liệu mới nhất.

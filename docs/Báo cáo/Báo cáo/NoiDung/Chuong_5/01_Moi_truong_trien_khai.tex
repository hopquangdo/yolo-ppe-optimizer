\section{Môi trường triển khai}

\subsection{Cloud Server}

Cloud Server chạy các dịch vụ Control Plane, cơ sở dữ liệu, message broker,
object storage và giao diện. Môi trường thực tế gồm \cbs{CPU, RAM, hệ điều hành},
được đóng gói bằng \cbs{Docker Compose/Kubernetes/cách triển khai thực tế}.
Các phiên bản runtime, database và broker được khóa trong tệp cấu hình để môi
trường có thể tái tạo.

\subsection{Jetson Nano}

Jetson Nano được cài \cbs{JetPack}, CUDA \cbs{phiên bản}, TensorRT
\cbs{phiên bản} và Edge Agent. Agent chạy dưới tài khoản dịch vụ, có quyền giới
hạn với thư mục model, runtime socket và thiết bị camera. Power mode, clock và
cấu hình quạt được cố định cho mỗi bài đo.

\subsection{Jetson Orin Nano}

Jetson Orin Nano sử dụng image hệ thống và dependency tương ứng với thiết bị.
Mặc dù API của Agent và Runtime giống Jetson Nano, TensorRT engine được build
riêng theo device class. Capability report cho biết compute capability, RAM,
TensorRT version và precision hỗ trợ.

\subsection{Network}

Cloud và Edge kết nối qua \cbs{LAN/VPN/Internet thực tế}. MQTT hoặc message
broker dùng TLS; artifact tải qua HTTPS hoặc object storage URL có thời hạn. Bài
kiểm thử mạng mô phỏng mất kết nối, trễ và giới hạn băng thông để xác nhận cơ chế
retry, offline buffer và resume download.

\section{Benchmark Edge Runtime}

Benchmark Edge Runtime đo toàn chuỗi thay vì chỉ TensorRT. Timer được đặt tại
ranh giới các stage; end-to-end latency tính từ lúc nhận frame đến lúc tạo detection.
Frame drop và queue depth phải được theo dõi để tránh báo cáo FPS cao trong khi
latency tích lũy.

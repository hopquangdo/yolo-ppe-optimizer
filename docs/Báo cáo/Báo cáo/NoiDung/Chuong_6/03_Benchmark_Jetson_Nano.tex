\section{Benchmark trên Jetson Nano}

Jetson Nano được dùng để kiểm tra cấu hình trong điều kiện tài nguyên hạn chế.
Mỗi engine chạy với cùng input, batch size và power mode. GPU memory được lấy
sau warm-up; power là giá trị tổng hợp trong cửa sổ chạy ổn định.

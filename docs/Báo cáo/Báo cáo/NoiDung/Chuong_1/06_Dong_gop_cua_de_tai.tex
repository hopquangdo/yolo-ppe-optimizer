\section{Đóng góp của đề tài}

Các đóng góp chính dự kiến của đồ án gồm:

\begin{enumerate}
  \item Một quy trình thực nghiệm thống nhất để so sánh YOLO baseline, pruning,
        QAT, pruning kết hợp QAT và TensorRT trên hai thế hệ Jetson.
  \item Một cơ chế đóng gói model artifact kèm phiên bản, hàm băm, cấu hình tiền
        xử lý--hậu xử lý, thông tin tương thích và kết quả benchmark.
  \item Một nền tảng Cloud--Edge quản lý Fleet, Model Registry, Deployment,
        Runtime, Monitoring và Incident theo desired state và actual state.
  \item Một Edge Agent hỗ trợ giao tiếp bất đồng bộ, cập nhật mô hình nguyên tử,
        giám sát runtime, bộ đệm telemetry và rollback khi triển khai thất bại.
  \item Một AI Copilot kết hợp Knowledge Retrieval với công cụ nghiệp vụ, cho
        phép giải thích trạng thái và lập kế hoạch thao tác có kiểm soát.
  \item Một bộ kịch bản đánh giá xuyên suốt từ tối ưu mô hình đến triển khai,
        phát hiện suy giảm FPS, tạo incident, phân tích và rollback.
\end{enumerate}

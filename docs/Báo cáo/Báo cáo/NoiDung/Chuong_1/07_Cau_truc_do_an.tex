\section{Cấu trúc đồ án}

Ngoài phần đầu báo cáo, tài liệu tham khảo và phụ lục, đồ án gồm bảy chương.
Chương 1 trình bày bối cảnh, mục tiêu, phạm vi và đóng góp. Chương 2 hệ thống
hóa cơ sở lý thuyết theo pipeline từ Edge AI, YOLO, nén và lượng tử mô hình đến
TensorRT, triển khai phân tán, RAG, AI Agent và Domain-Driven Design.

Chương 3 trình bày nghiên cứu tối ưu YOLO, xây dựng baseline, pruning, QAT,
kết hợp pruning--QAT và lựa chọn model triển khai. Chương 4 phân tích yêu cầu,
thiết kế domain và kiến trúc nền tảng Edge AI. Chương 5 mô tả quá trình xây dựng
Cloud, Edge Agent, Edge Runtime, Monitoring, giao diện và AI Copilot.

Chương 6 trình bày môi trường thực nghiệm, benchmark mô hình trên Jetson Nano
và Jetson Orin Nano, benchmark toàn pipeline và đánh giá nền tảng. Chương 7 tổng
kết kết quả, phân tích hạn chế và đề xuất hướng phát triển.

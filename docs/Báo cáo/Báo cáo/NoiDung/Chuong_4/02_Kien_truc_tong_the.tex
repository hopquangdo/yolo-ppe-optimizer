\section{Kiến trúc tổng thể}

Kiến trúc tổng thể được thể hiện trong Hình~\ref{fig:platform-architecture}. Người
dùng thao tác qua Dashboard hoặc Copilot. Cloud Control Plane cung cấp các
domain service và phát command qua message bus. Mỗi Edge Agent quản lý một AI
Runtime gắn với camera và gửi actual state, metric, event trở lại Cloud.

Control Plane là nguồn sự thật cho desired state; Edge Agent là nguồn sự thật
cho actual state tức thời. Hai trạng thái không bị đồng nhất: chênh lệch giữa chúng
là tín hiệu để hệ thống tiếp tục reconcile hoặc tạo incident. Dịch vụ không gọi
trực tiếp vào nội bộ domain khác mà dùng API/event đã công bố.

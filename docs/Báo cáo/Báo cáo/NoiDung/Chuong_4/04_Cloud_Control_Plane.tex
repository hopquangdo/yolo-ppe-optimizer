\section{Thiết kế Cloud Control Plane}

\subsection{Fleet Service}

Fleet Service cung cấp API đăng ký, tra cứu node, cập nhật label và capability.
Heartbeat consumer cập nhật last-seen và actual state theo sequence number để
không ghi đè dữ liệu mới bằng bản tin cũ. Node identity được liên kết với thông tin
xác thực của kết nối Edge.

\subsection{Model Registry}

Model Registry Service phát hành presigned URL hoặc cơ chế tải tương đương cho
artifact. Khi upload hoàn tất, dịch vụ kiểm tra checksum, metadata và trạng thái
validation. Chỉ artifact released và tương thích target mới được Deployment tham
chiếu.

\subsection{Deployment Service}

Deployment Service tạo target snapshot, chia batch, phát command và tổng hợp
kết quả. State machine của rollout được lưu bền vững để dịch vụ có thể tiếp tục
sau khi khởi động lại. Scheduler không gửi batch mới khi batch hiện tại chưa đạt
điều kiện thành công.

\subsection{Command Service}

Command Service ghi command trước khi publish, theo dõi acknowledgement và áp
dụng timeout/retry. Retry giữ nguyên idempotency key để Edge Agent nhận biết lệnh
đã thực thi. Kết quả được phát thành event cho Deployment, Audit và Incident.

\subsection{Incident Service}

Incident Service nhận detection event, áp dụng deduplication/correlation và tạo
incident. Service quản lý timeline, comment, assignment, acknowledgement và
resolution. Copilot chỉ đề xuất thao tác; thay đổi severity hoặc đóng incident vẫn
đi qua authorization của Incident domain.

\subsection{Knowledge Service}

Knowledge Service xử lý ingestion, chunking, embedding, keyword index và hybrid
search. API \texttt{search()} trả danh sách ứng viên ngắn; API \texttt{get()} trả
nội dung đầy đủ theo quyền. Tách hai bước giúp Agent chọn tài liệu trước khi đưa
nội dung lớn vào context.

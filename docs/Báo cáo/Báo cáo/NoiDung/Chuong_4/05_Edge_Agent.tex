\subsection{Command Processing}

Command Handler kiểm tra chữ ký hoặc danh tính nguồn, schema, deadline,
expected state và idempotency key. Lệnh hợp lệ được ghi vào local store trước khi
thực thi. Agent gửi acknowledgement sớm, sau đó báo running và kết quả cuối với
reason code chi tiết.

\subsection{Desired State và Actual State}

State Manager duy trì desired state nhận từ Cloud và actual state quan sát tại
node. Reconcile loop so sánh hai trạng thái, sinh hành động nhỏ và có thể lặp.
Version giúp bỏ qua desired state cũ đến muộn.

\subsection{Model Lifecycle}

Model lifecycle gồm download, verify, stage, validate, activate, retain và remove.
Artifact được tải vào thư mục tạm, kiểm tra checksum và compatibility trước khi
đổi con trỏ active. Phiên bản trước được giữ đến khi model mới vượt health check.

\subsection{Runtime Lifecycle}

Runtime Manager tạo process/container, truyền cấu hình, theo dõi health và thu
exit code. Start/stop/restart là thao tác idempotent. Khi runtime lỗi lặp lại, Agent
giới hạn restart để tránh vòng lặp gây quá tải và phát event cho Incident.

\subsection{Telemetry}

Telemetry Collector thu metric thiết bị và runtime theo chu kỳ. Dữ liệu được gắn
timestamp, node id, runtime id, model version và sequence number. Bộ đệm ngoại
tuyến có giới hạn dung lượng, ưu tiên event/incident hơn metric độ phân giải cao.

\begin{figure}[H]

Trước rollout, Deployment kiểm tra trạng thái released, compatibility, target và
quyền người dùng. Edge Agent thực hiện stage-and-switch: tải model mới trong khi
runtime cũ vẫn chạy, xác minh engine, sau đó chuyển active version. Health check
sau activation quyết định commit hoặc rollback.

Canary deployment chọn một nhóm node đại diện cho từng device class. Sau cửa sổ
quan sát, hệ thống so sánh error rate, FPS, latency, nhiệt độ và incident với
baseline. Rollout chỉ tiếp tục khi mọi guardrail đạt yêu cầu.

\subsection{Non-functional Requirements}

\begin{itemize}
  \item \textbf{Performance:} command và telemetry có độ trễ trong ngưỡng; API
        và Dashboard phản hồi được ở quy mô thí nghiệm.
  \item \textbf{Scalability:} dịch vụ stateless có thể nhân bản; luồng telemetry
        và command được phân vùng theo node hoặc tenant.
  \item \textbf{Reliability:} Edge tiếp tục inference khi Cloud gián đoạn; command
        có idempotency; deployment hỗ trợ retry và rollback.
  \item \textbf{Security:} xác thực node/người dùng, TLS, RBAC, checksum artifact,
        secret management và audit log theo nguyên tắc đặc quyền tối thiểu
        \cite{nist800207}.
  \item \textbf{Observability:} mọi dịch vụ phát metric, structured log, trace hoặc
        correlation id đủ để truy nguyên một deployment từ Cloud đến Edge.
\end{itemize}

Các ngưỡng định lượng cho từng yêu cầu được xác định trong Chương 6 dựa trên
môi trường thực nghiệm thực tế.

\section{Kết hợp Pruning và QAT}

\subsection{Quy trình kết hợp}

Quy trình kết hợp được thể hiện trong Hình~\ref{fig:pruning-qat-pipeline}. Pruning
được thực hiện trước để thay đổi cấu trúc; fine-tuning phục hồi accuracy; QAT sau
đó giúp mô hình thích nghi với INT8 trước khi tạo TensorRT engine.

\begin{figure}[H]
\centering

  \node[flowbox, below=of fine] (qat) {QAT};
  \node[flowbox, below=of qat] (int8) {INT8};
  \node[flowbox, below=of int8] (trt) {TensorRT};
  \draw[flowarrow] (yolo) -- (prune);
  \draw[flowarrow] (prune) -- (fine);
  \draw[flowarrow] (fine) -- (qat);
  \draw[flowarrow] (qat) -- (int8);
  \draw[flowarrow] (int8) -- (trt);

\subsection{So sánh kết quả}

So sánh tập trung vào mức thay đổi accuracy và speedup so với baseline. Cần đặc
biệt kiểm tra xem pruning và QAT có cộng dồn suy giảm hay không, đồng thời đánh
giá lợi ích thực trên từng thiết bị. Kết quả chi tiết được trình bày ở Chương 6;
chương này mô tả quy trình và tiêu chí lựa chọn.

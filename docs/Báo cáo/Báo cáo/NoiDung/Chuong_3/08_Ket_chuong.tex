\section{Kết chương}

Chương 3 đã xây dựng quy trình từ YOLO baseline đến pruning, QAT, kết hợp hai
kỹ thuật và tạo TensorRT engine. Quy trình đặt accuracy ngang hàng với latency,
FPS, model size, GPU memory và power, đồng thời yêu cầu truy vết từ artifact về
thí nghiệm. Chương 4 sử dụng model artifact và các yêu cầu vòng đời này để phân
tích, thiết kế nền tảng Edge AI.

\noindent\textbf{Tên đề tài:} NGHIÊN CỨU VÀ XÂY DỰNG NỀN TẢNG EDGE AI TÍCH HỢP
AI AGENT VÀ TỐI ƯU MÔ HÌNH YOLO

\noindent\textbf{Sinh viên thực hiện:} Đỗ Quang Hợp

\noindent\textbf{Mã SV:} 68CNCS \hspace{3cm} \textbf{Lớp:} 68CS2

Đồ án nghiên cứu đồng thời hai vấn đề: tối ưu mô hình YOLO cho thiết bị Edge AI
và xây dựng nền tảng quản lý vòng đời AI trên một đội thiết bị phân tán. Ở phần
mô hình, đồ án xây dựng pipeline tối ưu YOLO26n cho bài toán phát hiện trang bị
bảo hộ lao động gồm: tìm siêu tham số bằng thuật toán Sea-Horse Optimizer, thưa
hóa BatchNorm, cắt tỉa kênh có cấu trúc, phục hồi độ chính xác bằng chưng cất tri
thức Channel-Wise Distillation, Quantization-Aware Training và chuyển đổi sang
TensorRT INT8. Cắt tỉa 30\% giảm 15,7\% số tham số và 21,2\% FLOPs của mô hình;
các thực nghiệm sơ bộ kiểm chứng từng giai đoạn và cho thấy ảnh hưởng của lịch
thưa hóa, ngân sách phục hồi và trọng số chưng cất.

Ở phần nền tảng, đồ án xây dựng kiến trúc Cloud Control Plane -- Edge Data Plane.
Cloud Server (FastAPI, PostgreSQL, Redis) quản lý cluster, node, runtime và
deployment theo mô hình desired state, giao tiếp với thiết bị qua MQTT. Edge Agent
điều khiển container AI Runtime bằng các thao tác idempotent, lưu desired state,
chống lệnh trùng và tự phục hồi runtime lỗi; AI Runtime chạy YOLO trên luồng camera
và báo cáo telemetry theo một đặc tả thống nhất. Hệ thống có Web Dashboard theo
dõi realtime qua WebSocket, giám sát hạ tầng bằng Prometheus và AI Assistant xây
dựng trên LangGraph truy cập hệ thống qua 17 công cụ Model Context Protocol với cơ
chế kiểm soát thao tác ghi. Toàn bộ được đóng gói container và triển khai tự động
lên AWS EC2 bằng GitHub Actions; 17/18 kiểm thử tự động của luồng triển khai đầu
cuối đạt yêu cầu.

\noindent\textbf{Từ khóa:} Edge AI, YOLO26, pruning, knowledge distillation, QAT,
TensorRT, Jetson, MQTT, desired state, AI Agent, MCP.

\section{Cấu trúc đồ án}

Ngoài phần đầu báo cáo, tài liệu tham khảo và phụ lục, đồ án gồm bảy chương.
Chương 1 trình bày bối cảnh, mục tiêu, phạm vi và đóng góp. Chương 2 hệ thống
hóa cơ sở lý thuyết theo pipeline từ Edge AI, YOLO, nén và lượng tử mô hình đến
TensorRT, triển khai phân tán, RAG, AI Agent và Domain-Driven Design.

Chương 3 trình bày pipeline tối ưu YOLO26n: baseline với siêu tham số tìm bằng
SHO, thưa hóa và cắt tỉa kênh, chưng cất tri thức, QAT, chuyển đổi TensorRT và
lựa chọn model triển khai. Chương 4 phân tích yêu cầu, thiết kế domain và kiến
trúc nền tảng Edge AI. Chương 5 mô tả quá trình xây dựng Cloud Server, Edge Agent,
AI Runtime, AI Assistant, giám sát, Web Dashboard và CI/CD.

Chương 6 trình bày môi trường thực nghiệm, kết quả tối ưu mô hình, benchmark
trên Jetson Nano và Jetson Orin Nano, và kiểm chứng nền tảng. Chương 7 tổng
kết kết quả, phân tích hạn chế và đề xuất hướng phát triển.

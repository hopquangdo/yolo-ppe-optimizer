\chapter{MODEL TRAINING CONFIGURATION}

\begin{lstlisting}[caption={Cấu hình pipeline tối ưu trong notebook}]
# --- du lieu va mo hinh ---
MODEL    = weights/yolo26n.pt        # student / diem xuat phat
TEACHER  = weights/yolo26l.pt        # teacher chung cat
DATA     = construction-ppe.yaml     # 1132/143/141 anh, 11 lop
IMG_SIZE = 640
BATCH    = 16

# --- SHO + baseline ---
BASELINE_EPOCHS = 100
SHO_POP, SHO_GMAX, SHO_PROXY_EPOCHS = 6, 3, 3

# --- sparsity (Network Slimming) ---
SPARSITY_EPOCHS = 200
SPARSITY_SR     = 1e-2               # giam dan: sr * (1 - 0.9 * epoch / epochs)

# --- pruning ---
PRUNE_RATIO = 0.30

# --- phuc hoi ---
RECOVERY_MODE   = 'distill'          # hoac 'finetune'
RECOVERY_EPOCHS = 100
LAMBDA_CWD      = 50.0
KD_TEMPERATURE  = 4.0

# --- QAT (TensorRT INT8) ---
QAT_EPOCHS        = 20
QAT_BATCH         = 8
QAT_LR0           = 1e-3             # chia 100 ben trong QATTrainerYolo26
QAT_CALIB_BATCHES = 256              # hieu chinh entropy
\end{lstlisting}

\begin{lstlisting}[caption={Trình tự lệnh của pipeline}]
python scripts/sho_search.py   --model yolo26n.pt --data construction-ppe.yaml \
       --pop 6 --gmax 3 --proxy-epochs 3 --full-epochs 100 --imgsz 640 --batch 16
python scripts/train_sparsity.py --weights <baseline best.pt> --epochs 200 --sr 1e-2
python scripts/prune.py        --weights sparsity.pt --model-size n --prune-ratio 0.30
python scripts/distill.py      --teacher yolo26l.pt --student-checkpoint yolo26_pruned.pt \
       --epochs 100 --lambda-cwd 50 --temperature 4.0
python scripts/qat.py          --checkpoint recovered.pt --epochs 20 --batch 8 \
       --lr0 1e-3 --calib-batches 256
\end{lstlisting}

Mỗi run lưu \texttt{args.yaml} (toàn bộ tham số, seed, \texttt{deterministic})
và \texttt{results.csv} (loss và chỉ số theo epoch) cùng thư mục
\texttt{weights/} chứa \texttt{best.pt} và \texttt{last.pt}.

\chapter{DATABASE SCHEMA}

Schema PostgreSQL được tạo bởi hai migration trong \path{db/migrations}. Khóa
chính là UUID sinh bởi \texttt{gen\_random\_uuid()} (extension \texttt{pgcrypto});
mọi bảng có \texttt{created\_at}, phần lớn có \texttt{updated\_at} cập nhật bằng
trigger; thuộc tính mở rộng lưu kiểu \texttt{JSONB}.

Các kiểu enum (\texttt{node\_status}, \texttt{runtime\_status},
\texttt{deployment\_status}...) có giá trị trùng khớp với enum Python trong
\texttt{src/shared/contracts/enums.py}. Chỉ mục được tạo trên các cột lọc thường
dùng: \texttt{nodes(cluster\_id)}, \texttt{nodes(status)},
\texttt{nodes(last\_heartbeat\_at)}, \texttt{deployments(node\_id)},
\texttt{deployments(runtime\_id)}, \texttt{deployments(status)}.

\begin{lstlisting}[caption={Bảng deployments (V002)}]
CREATE TABLE deployments (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    cluster_id UUID NOT NULL REFERENCES clusters(id) ON DELETE CASCADE,
    node_id    UUID NOT NULL REFERENCES nodes(id)    ON DELETE CASCADE,
    runtime_id UUID NOT NULL,          -- khong FK: giu lich su sau khi runtime bi xoa
    spec JSONB NOT NULL,
    status deployment_status NOT NULL DEFAULT 'PENDING',
    last_command_id VARCHAR(64),
    message TEXT,
    created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW()
);
\end{lstlisting}
